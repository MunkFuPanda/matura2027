# DNA Replikation

- Topoisomerase => entwirrt die Helixe
- Helikase => Spaltet die Helixe
- DNA-Polymerase => baut den neuen Strang
- Primer => "der Erste" => sind der Startpunkt der Polymerase
- Okazaki-Fragment entsteht
- Primer werden entfernt, DNA ist kopiert
- Primer setzt sich immer an das 3´ Ende

# RNA
