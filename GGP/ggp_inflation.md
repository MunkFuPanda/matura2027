# 2.7 Deflation

Deflation ist gefährlicher!
Was ist die Folge?
Unternehmen und Privatpersonen zögern ihren Konsum und ihre Investitionen hinaus,
da sie annehmen dass die Preise noch weiter fallen ->
Nachfrage sinkt -> Arbeitsplätze werden abgebaut -> Löhne sinken ->
Nachfrage reduziert sich noch weiter
Deshalb ist eine gewisse Inflation (ca. 2% pro Jahr) immer gewünscht

| Inflation   | Deflation    |
|--------------- | --------------- |
| Preissteigerungen   | Preissturz   |
| Sinken des Geldwertes   | Steigen des Geldwertes   |
| Flucht in Sachwerte   | Flucht in das Geld   |
| Nachteile für Gläubiger   | Vorteile für Gläubiger   |
| Vorteile für Schuldner  | Nachteile für Schuldner   |
